## 零、先做能力重合度判定（这一步决定 60% 的东西不用看）

两个项目**不是一个物种**：

| 维度 | hyxapi | workbuddy2api | 结果 |
|---|---|---|---|
| 形态 | 多租户 SaaS 网关 | **单管理员自用**反代 | 用户/计费/订阅/工单**全部不需要** |
| 规模 | 356 条路由 · 1770 文件 | 3 条入站路由 · 410 源码文件 | 路由/权限/多语言**不需要** |
| 上游管理 | **渠道**（管理员配 base_url + key） | **账号池**（多账号 + 免费额度 + 登录器） | ⇒ **它的渠道选择比你弱，别反向搬** |
| 协议面 | 入站 4 种（Chat/Responses/Claude/Gemini） | 入站 **1 种**（OpenAI Chat）+ Images | ⇒ **最大真实缺口** |
| 上游适配 | 配置驱动 | **11 个手写 Go 包** | 各有取舍 |
| 安全模型 | RBAC/CASBIN/2FA/Passkey/step-up | 单 token | ⇒ **不需要** |

### 开箱即弃（连表都不用列）

**用户体系**：注册 / 登录 / 2FA / Passkey-WebAuthn / OAuth 用户 SSO / 邮箱验证
**计费体系**：钱包 / 充值 / 订阅 / 6 家支付 / 分组倍率 / 表达式定价 / 预扣-后补
**多租户**：RBAC + CASBIN / 权限矩阵 / 工单 / 公告 / 邀请码
**国际**：i18n 整套（go-i18n + 3 YAML + 4 级语言解析）
**其它**：task_plugin(1487行) / mj·suno·video·audio·realtime 全套端点 / getModelRequest(700行)
