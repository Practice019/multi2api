# Key 状态 操作
多把 Key 时按这里的方式挑一把用。某把被上游判为无效（401/403）会**自动只禁用那一把**，不停整条渠道 —— 恢复在上面的表格里点「启用」。
这里写上游认识的名字；对外想换名字就用下面的映射。
对外名字 = 左边（客户端写它），上游真实名 = 右边。留空即名字相同。
优先级高的先用；同一优先级内按权重随机（权重只影响"同档选谁"）。
