分组管理

分组即模型集合
名称描述模型数引用创建时间操作

分组只回答「允许哪些模型」。同一批模型由哪条渠道提供、按什么优先级/权重选路，是渠道页与能力索引的事。
删除分组会级联清理所有 API Key 里对它的引用；若某把 key 因此没有分组了， 它会变成不限制（可用全部模型）—— 删除时会当场告知是哪几把。

新增分组
名称唯一（重名会被拒绝）。它只是展示名 —— API Key 引用的是分组 ID，改名不会断链。
已选模型（点 × 取消）
每个已选模型自动一行。左边是内部模型名（固定），右边是对外显示名 —— 默认与左边相同，改右边就能改对外叫法。
多个模型可以填同一个对外名：那样对外只出现一个名字， 调用时在这些上游之间轮询，某个失败自动换下一个。
